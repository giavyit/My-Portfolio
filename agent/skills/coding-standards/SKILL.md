# Coding Standards

1. Use TypeScript for all files.
2. Ensure components are placed in `components/` using Atomic Design (atoms, molecules, organisms).
3. Use Tailwind CSS for styling and `cn()` from `lib/utils` for class merging.
4. Follow ESLint and SonarQube rules (Zero warnings).
5. Prefer Functional Components with React Hooks.
